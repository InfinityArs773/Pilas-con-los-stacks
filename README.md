En este mini programita se implementa una estructura de datos tipo **Pila (Stack)** mediante nodos en el lenguaje de programación Java

## Metodos implementados
- `push()`: agrega un elemento al tope.
- `pop()`: extrae el elemento del tope.
- `peek()`: consulta el elemento del tope sin extraerlo.
- `empty()`: verifica si la pila está vacía.
